# COVID-Era Mandate Source Artifacts

This folder preserves proof-grade source packets for brittle or time-sensitive COVID-era mandate materials used in the corpus.

## Purpose

The translation files already contain the legal or policy analysis. These artifact files preserve the source-side evidence needed to defend later claims about what the source actually said, even if the live page changes, disappears, or becomes hard to retrieve.

Each packet should preserve:

- source title
- organization / issuing body
- original URL when known
- archived URL when applicable
- source descriptor when an exact URL was not preserved at filing time
- capture or retrieval date
- exact operative lines relied on in the batch
- the corpus batch or file that uses the source
- short provenance note explaining why this packet exists
